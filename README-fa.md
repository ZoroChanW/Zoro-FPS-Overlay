# Zoro FPS Overlay

![Platform: Windows 10/11](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-lightgrey)
![Built with Rust](https://img.shields.io/badge/built%20with-Rust-orange)
![License: MIT](https://img.shields.io/badge/license-MIT-blue)

یک FPS overlay سبک و مینیمال برای Windows. FPS، frametime، 1% low و درصد مصرف CPU / RAM / GPU رو روی بازی نشون می‌ده، **بدون اینکه چیزی داخل بازی inject کنه**.

## ویژگی‌ها

- **شش نمایشگر که تک‌تک قابل روشن/خاموش شدن هستن:** FPS، frametime، 1% low، مصرف CPU، مصرف RAM و مصرف GPU.
- **چیدمان ستونی یا ردیفی:** نمایشگرها رو زیر هم یا کنار هم بچین.
- **بدون inject و hook:** زمان فریم‌ها از [PresentMon](https://github.com/GameTechDev/PresentMon) می‌آد و overlay یه پنجره‌ی جدا و click-through هست. هیچ کدی داخل پروسه‌ی بازی لود نمی‌شه.
- **قابل تنظیم:** ۹ نقطه‌ی صفحه با offset پیکسلی، ۷ فونت، اندازه، رنگ، Bold، سایه‌ی متن، برچسب‌ها و فاصله‌ها، همراه با پیش‌نمایش زنده.
- **اعمال فوری تغییرات:** تنظیمات رو ذخیره کنی، overlay در حال اجرا ظرف نیم‌ثانیه به‌روز می‌شه.
- **سبک:** پنجره‌ی تنظیمات با `egui`/`eframe` ساخته شده و فقط وقتی بازه که لازمش داری.

## چی نشون می‌ده

| نمایشگر | معنی |
| --- | --- |
| **FPS** | میانگین ۳۰ فریم آخر. |
| **Frametime** | میانگین زمان هر فریم در ۳۰ فریم آخر، به میلی‌ثانیه. |
| **1% low** | کندترین ۱٪ از حدود ۶۰۰ فریم آخر، تبدیل‌شده به FPS. بعد از جمع شدن حدود ۶۰ فریم ظاهر می‌شه. |
| **CPU usage** | بار کل پردازنده روی همه‌ی هسته‌ها. |
| **RAM usage** | درصد حافظه‌ی فیزیکی در حال استفاده. |
| **GPU usage** | بار شلوغ‌ترین engine کارت گرافیک، از Performance Counter های «GPU Engine» ویندوز (همون منبعی که Task Manager استفاده می‌کنه). با NVIDIA، AMD و Intel کار می‌کنه. |

شمارنده‌های GPU فقط وقتی خونده می‌شن که نمایشگر GPU روشن باشه.

## شروع کار

### ساخت از روی سورس

**پیش‌نیازها:** Windows 10 یا 11، Rust و Cargo. بار اول، Cargo باید بتونه `eframe` و وابستگی‌هاش رو از crates.io دانلود کنه.

1. این ریپو رو clone یا دانلود کن.
2. PowerShell رو توی پوشه‌ی پروژه باز کن و PresentMon رو دانلود کن:

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\scripts\download-presentmon.ps1
   ```

3. فایل `build-release.bat` رو اجرا کن.
4. فایل اجرایی اینجا ساخته می‌شه:

   ```text
   target\release\zoro-fps-overlay.exe
   ```

> **مهم:** فایل `PresentMon.exe` باید کنار `zoro-fps-overlay.exe` بمونه.

### استفاده

1. فایل `zoro-fps-overlay.exe` رو بدون آرگومان اجرا کن تا پنجره‌ی تنظیمات باز بشه.
2. انتخاب کن چه نمایشگرهایی باشن، کجا قرار بگیرن و چه ظاهری داشته باشن. پیش‌نمایش بالای صفحه همزمان با تغییرات عوض می‌شه.
3. روی **Save & Start** بزن. تنظیمات ذخیره می‌شن، overlay اجرا می‌شه و پنجره‌ی تنظیمات بسته می‌شه. **Save** فقط ذخیره می‌کنه و **Reset** مقدارهای پیش‌فرض رو برمی‌گردونه (با Save اعمال می‌شن).
4. بازی رو اجرا کن. در حالت پیش‌فرض **Games only**، وقتی برنامه‌ی جلوی صفحه یه لحظه فریم تولید کرد overlay ظاهر می‌شه و روی دسکتاپ، پنجره‌های سیستمی و برنامه‌های روزمره مثل مرورگر دوباره مخفی می‌شه.

هر موقع خواستی می‌تونی پنجره‌ی تنظیمات رو دوباره باز کنی. بستنش overlay رو نمی‌بنده.

### میان‌برها

| کلید | کار |
| --- | --- |
| `F8` | نمایش یا مخفی کردن overlay |
| `F10` | خروج کامل از overlay |

## شخصی‌سازی

| گزینه | توضیح |
| --- | --- |
| **Position** | ۹ نقطه‌ی صفحه (گوشه‌ها، لبه‌ها، وسط) به‌علاوه‌ی offset های X/Y بر حسب پیکسل. X مثبت یعنی راست و Y مثبت یعنی پایین، با هر anchor ای. |
| **Layout** | Column (هر آیتم یک خط) یا Row (آیتم‌ها کنار هم). فاصله برای هر کدوم جدا تنظیم می‌شه. |
| **Items** | FPS، frametime، 1% low، CPU، RAM، GPU. حداقل یکی همیشه روشن می‌مونه. |
| **Labels** | نمایش `CPU 23%` یا فقط `23%`. |
| **Font** | Segoe UI، Consolas، Arial، Tahoma، Verdana، Bahnschrift یا Courier New. فونت باید روی سیستم نصب باشه. Consolas رقم‌ها رو هم‌عرض نگه می‌داره. |
| **اندازه و رنگ** | اندازه‌ی متن از ۱۸ تا ۶۴ پیکسل و هر رنگ `RRGGBB`. مشکی خالص (`000000`) مجاز نیست، چون رنگ شفاف‌شدن overlay هست. |
| **Style** | متن Bold و سایه‌ی نرم اختیاری. |

تنظیمات توی `%APPDATA%\ZoroFPSOverlay\settings.ini` ذخیره می‌شن. overlay در حال اجرا هر ۵۰۰ میلی‌ثانیه این فایل رو چک می‌کنه و تغییرات رو خودش اعمال می‌کنه.

## طرز کار

- **زمان فریم‌ها** رو یه پروسه‌ی مخفی [PresentMon](https://github.com/GameTechDev/PresentMon) که برنامه‌ی جلوی صفحه رو زیر نظر داره می‌خونه. overlay خروجی CSV اون رو پردازش می‌کنه و FPS، frametime و 1% low رو حساب می‌کنه.
- **خود overlay** یه پنجره‌ی Win32 شفاف، همیشه روی بقیه و click-through هست. اندازه‌ش دقیقاً به اندازه‌ی متنشه، برای همین متن سمت راست می‌تونه تا خود لبه‌ی مانیتور بره.
- **CPU و RAM** از `GetSystemTimes` و `GlobalMemoryStatusEx` می‌آن. **GPU** از Performance Counter های «GPU Engine» ویندوز (PDH) می‌آد. همه هر ثانیه یک بار به‌روز می‌شن.
- **پنجره‌ی تنظیمات** تنها بخشیه که از `egui`/`eframe` استفاده می‌کنه (با رندر Glow، تا stack پیش‌فرض `wgpu` اضافه نشه).

هیچ چیزی داخل بازی inject نمی‌شه و حافظه‌ی بازی خونده نمی‌شه.

## محدودیت‌ها

- **فقط Windows**، تست‌شده روی Windows 10 و 11.
- بازی‌های **Fullscreen Exclusive** ممکنه overlay رو بپوشونن. بازی‌های Windowed، Borderless و بیشتر بازی‌های DirectX 11/12 که «فول‌اسکرین» هستن (و ویندوز اون‌ها رو تقریباً مثل Borderless اجرا می‌کنه) کار می‌کنن. اندازه‌گیری FPS و کشیدن چیزی روی بازی دو مسئله‌ی جدا هستن و دومی دست ویندوز و خود بازیه.
- **GPU usage** به Performance Counter های «GPU Engine» ویندوز نیاز داره (Windows 10 نسخه‌ی 1709 به بعد با درایور WDDM 2.0 یا جدیدتر). اگه در دسترس نباشن، آیتم `GPU --` نشون می‌ده.
- **Anti-cheat:** overlay به پروسه‌ی بازی دست نمی‌زنه، ولی یه ابزار شخص ثالث حساب می‌شه. اگه بازی آنلاین با anti-cheat سخت‌گیر بازی می‌کنی، با صلاح‌دید خودت ازش استفاده کن.

## عیب‌یابی

overlay دو فایل لاگ توی پوشه‌ی temp (`%TEMP%`) می‌نویسه:

- `zoro-fps-overlay-diagnostic.log` برای کارهایی که overlay انجام می‌ده، از جمله دلیل در دسترس نبودن شمارنده‌های GPU.
- `zoro-fps-overlay-presentmon.log` برای خروجی خطای خود PresentMon.

| مشکل | کاری که می‌شه کرد |
| --- | --- |
| overlay هیچ‌وقت ظاهر نمی‌شه | مطمئن شو `PresentMon.exe` کنار فایل اجرایی هست و بازی پنجره‌ی جلوی صفحه است. شاید با `F8` مخفی شده باشه. |
| `FPS ERR` | PresentMon اجرا نشده یا بسته شده. لاگ PresentMon رو ببین. |
| `FPS ...` | منتظر اولین فریم‌های بازی هستیم. |
| `GPU --` | شمارنده‌های GPU در دسترس نیستن یا هنوز آماده نشدن. چند ثانیه صبر کن، بعد لاگ diagnostic رو ببین. |
| overlay توی یه بازی دیده نمی‌شه | احتمالاً بازی Exclusive Fullscreen هست. حالتش رو به Borderless یا Windowed عوض کن. |

## overlay چه موقع نمایش داده می‌شه

- **Games only** (پیش‌فرض): برنامه‌ی جلوی صفحه با PresentMon اندازه‌گیری می‌شه. وقتی حدود ۱.۲ ثانیه حداقل ۱۰ فریم بر ثانیه تولید کنه overlay ظاهر می‌شه و تا وقتی ۵ ثانیه فریمی نیاد می‌مونه. پس صفحه‌ی لودینگ یا صحنه‌ی با FPS پایین هیچ‌وقت اون رو مخفی نمی‌کنه و یه alt-tab کوتاه هم باعث پرش (flicker) نمی‌شه. مرورگرها، پخش‌کننده‌ها، پیام‌رسان‌ها، ادیتورها، ترمینال‌ها، برنامه‌های آفیس و لانچرهای بازی نادیده گرفته می‌شن.
- **All apps:** overlay روی هر برنامه‌ای که جلوی صفحه‌ست و فریم تولید می‌کنه نشون داده می‌شه.
- **قانون برای هر برنامه:** برنامه‌هایی که overlay دیده فریم تولید می‌کنن توی پنجره‌ی تنظیمات لیست می‌شن. هر کدوم رو می‌تونی روی **Show** (همیشه)، **Hide** (هیچ‌وقت) یا **Auto** بذاری. اسم پروسس رو هم می‌تونی دستی اضافه کنی و هر برنامه رو با دکمه‌ی `×` از لیست حذف کنی. قانون **Hide** از **Show** قوی‌تره.
- کلید `F8` overlay رو دستی مخفی می‌کنه. نمایش دوباره فقط وقتی کار می‌کنه که قوانین بخوان overlay دیده بشه.

تشخیص یه روش تخمینیه و تضمین صددرصدی نیست. اگه جایی اشتباه کرد، با یه قانون Show یا Hide برای اون برنامه همیشگی درستش می‌کنی.

## نقشه‌ی راه

ایده‌ها، نه قول:

- تشخیص Exclusive Fullscreen و ارائه‌ی راه جایگزین.
- پروفایل جدا برای هر بازی.
- دمای CPU/GPU و مصرف VRAM.

## تغییرات نسخه‌ها

**v0.6.1**
- حالا می‌شه برنامه‌ها رو با دکمه‌ی `×` از لیست **When to show** حذف کرد (قانون Show / Hide اون برنامه هم بعد از Save پاک می‌شه).

**v0.6.0**
- نمایش فقط روی بازی‌ها با زمان انتظار و hysteresis، بدون پرش و بدون مخفی شدن اشتباه توی بازی.
- قانون Auto / Show / Hide برای هر برنامه و حالت **All apps**.
- alt-tab کوتاه دیگه اندازه‌گیری رو از نو شروع نمی‌کنه.
- `F8` دیگه نمی‌تونه overlay رو روی دسکتاپ نشون بده.

**v0.5.0**
- نمایشگرهای مصرف CPU، RAM و GPU، که هر کدوم قابل روشن/خاموش شدنه.
- چیدمان ستونی و ردیفی با فاصله‌ی قابل تنظیم.
- انتخاب فونت، Bold، سایه‌ی متن و گزینه‌ی برچسب‌ها.
- پیش‌نمایش موقع اسکرول تنظیمات ثابت می‌مونه.

**v0.4.0**
- overlay چندخطی با FPS، frametime و 1% low.
- رفع باگ مشترک بودن اسکرول دو ستون تنظیمات.

**v0.3.2**
- رفع مشکل جای‌گیری سمت راست صفحه (Per-Monitor DPI awareness و پنجره‌ای که اندازه‌اش با متن می‌خونه).
- offset قابل‌پیش‌بینی: X مثبت به راست و Y مثبت به پایین.
- بازطراحی پنجره‌ی تنظیمات با پالت مینیمال مشکی، خاکستری و سفید استخوانی.
- نمایش `F8` و `F10` در سربرگ پنجره.

**v0.3.1**
- هماهنگ شدن با API رابط کاربری `egui`/`eframe` نسخه‌ی 0.37.
