# Zoro FPS Overlay v0.3.2

یک FPS overlay سبک برای Windows که برای اندازه‌گیری فریم از PresentMon استفاده می‌کند و برای تنظیم ظاهر از رابط گرافیکی مدرن **egui/eframe** بهره می‌برد.

## امکانات

- نمایش FPS با پنجره‌ی شفاف و click-through
- جست‌وجوی فرایند جلوی صفحه و دریافت فریم‌ها از PresentMon از طریق stdout
- پنجره‌ی تنظیمات مدرن با تم خاکستری/مشکی با سفید استخوانی
- انتخاب محل از میان ۹ نقطه‌ی صفحه و تنظیم دقیق X/Y برحسب پیکسل؛ مثبت بودن X همیشه به معنی حرکت به راست است و مثبت بودن Y به معنی حرکت به پایین
- پیش‌نمایش تقریبی محل و ظاهر Overlay
- تغییر اندازه و رنگ متن
- ذخیره‌ی تنظیمات در `%APPDATA%\ZoroFPSOverlay\settings.ini`
- اعمال خودکار تغییرات ذخیره‌شده روی Overlay در حال اجرا
- بستن پنجره‌ی تنظیمات بدون بستن Overlay
- میان‌بر `F8` برای مخفی/نمایش و `F10` برای بستن کامل Overlay؛ هر دو میان‌بر داخل GUI هم نمایش داده می‌شوند
- تنظیمات GUI از `eframe`/`egui` استفاده می‌کند؛ رندر آن با Glow انتخاب شده تا وابستگی‌های پیش‌فرض wgpu اضافه نشوند.

## ساخت در Windows

پیش‌نیازها: Rust و Cargo. در اولین بار، Cargo باید بتواند crateهای eframe و وابستگی‌های آن را از crates.io دریافت کند.

1. ZIP را استخراج کنید.
2. PowerShell را در پوشه‌ی پروژه باز کنید و اجرا کنید:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\download-presentmon.ps1
```

3. `build-release.bat` را اجرا کنید.
4. فایل اجرایی اینجاست:

```text
target\release\zoro-fps-overlay.exe
```

فایل `PresentMon.exe` باید کنار فایل اجرایی بماند.

## استفاده

- فایل اجرایی را بدون آرگومان اجرا کنید تا پنجره‌ی تنظیمات باز شود.
- محل، Offset، اندازه و رنگ را تغییر دهید.
- `Save changes` تنظیمات را ذخیره می‌کند.
- `Save & Start Overlay` تنظیمات را ذخیره و Overlay را اجرا می‌کند، سپس GUI بسته می‌شود.
- `Close` فقط GUI را می‌بندد.
- داخل بازی: `F8` نمایش/مخفی، `F10` خروج کامل.

پیش‌نمایش GUI نمونه‌ی نمایشی `144 FPS` است و عدد زنده‌ی بازی نیست.

## نکته‌ها

- پنجره‌ی شفاف Overlay با Win32 API ساخته شده تا egui در حلقه‌ی رندر دائمی FPS overlay دخالت نکند. egui فقط در پنجره‌ی تنظیمات استفاده می‌شود.
- Overlay هر ۵۰۰ میلی‌ثانیه فایل تنظیمات را بررسی می‌کند و در صورت تغییر، موقعیت و ظاهر را به‌روزرسانی می‌کند.
- نمایش Overlay روی Fullscreen Exclusive از طرف ویندوز و بازی تضمین‌شده نیست؛ دریافت FPS و نمایش پنجره دو قابلیت جدا هستند.
- نسخه در این محیط روی Windows کامپایل و تست نشده است. پس از دانلود، پروژه را با `build-release.bat` بسازید و هر خطای کامپایل را نگه دارید تا بتوان بررسی کرد.

## یادداشت نسخه 0.3.1
این نسخه با API رابط کاربری egui/eframe نسخه 0.37 هماهنگ شده است: استفاده از `Panel` به‌جای `TopBottomPanel` و اعمال Style با `style_of` و `set_style_of`.

## تغییرات v0.3.2

- اصلاح جای‌گیری سمت راست با فعال‌کردن Per-Monitor DPI Awareness V2 پیش از ساخت پنجره‌ها؛ جلوگیری از ناسازگاری مختصات صفحه با scaling ویندوز.
- جهت Offset قابل‌پیش‌بینی شد: مقدار مثبت X به راست و مقدار مثبت Y به پایین حرکت می‌کند، مستقل از anchor.
- بازطراحی UI با پالت مشکی، خاکستری و سفید استخوانی؛ حذف اکسنت بنفش و رنگ‌های تزئینی.
- میان‌برهای `F8` و `F10` در سربرگ قابل مشاهده‌اند.
